# Local SLM Observatory

## Project Overview
The Local SLM Observatory project aims to establish a benchmark for evaluating the performance of various models in the context of Spatial Language Models (SLM). This document serves as a comprehensive guide to understanding the architecture, models, tasks, results, setup instructions, and key findings of the project.

## Architecture
The architecture of the Local SLM Observatory consists of several components:
- **Data Collection**: Gathering data from various sources to feed into the models.
- **Model Training**: Implementing and fine-tuning the selected models based on the collected data.
- **Evaluation**: Assessing model performance using predefined metrics and benchmarks.

## Setup Instructions
To set up the Local SLM Observatory project, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/GauriGandhi200517/local-slm-benchmark.git
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the setup script:
   ```bash
   python setup.py
   ```
